# 3. 主な機能（詳細）

## HTTP リクエストの作成・送信

GET・POST・PUT・PATCH・DELETE などのメソッド選択、URL・クエリパラメータ・ヘッダの編集、JSON などの本文入力。送信、途中キャンセル（将来）、タイムアウトなどの通信設定（将来）、リダイレクトや接続エラーの適切な処理。

## レスポンスの表示

ステータスコードとステータステキスト、レスポンスヘッダ、本文、JSON の整形表示。レスポンス時間と受信サイズ、通信エラーやタイムアウトのエラー表示。

## リクエストの保存・整理

名前付き保存、フォルダ／コレクションによる分類（将来）、再実行、複製・編集・削除（将来）。実行履歴と実行時点の結果の保存。将来的なインポート／エクスポート。

## 環境変数と認証（将来。認証ヘッダーの手入力のみ今回対応）

`baseUrl`・API キー・トークンなどの変数定義、開発／テストなど環境セットの切り替え、URL・ヘッダ・本文での変数参照。Bearer Token・Basic 認証などのヘッダ設定、Cookie の確認・管理。ログイン API で取得したトークンを後続リクエストで利用。

## API テスト・シナリオ実行（将来）

ステータスコード・本文の値やキーの有無・レスポンス時間の上限などの検証。複数テストのまとめ実行。ログイン → データ取得 → 更新のようなシナリオ実行で、前のレスポンスから値を取り出して次へ渡す。成功／失敗と失敗理由の一覧表示。

## 通信観測・分析（将来）

ローカルプロキシの起動・停止、明示的にプロキシ設定したブラウザ等の通信観測。時刻・宛先・メソッド・ステータスの一覧、ヘッダ／本文の詳細、フィルタ、保存・エクスポート（将来）・再送。通信時間や失敗傾向の分析（将来）。

## API クライアントと観測の統合（将来）

観測した通信をワンクリックで API リクエストとして保存、再送して挙動を再現、通信データからテストケースを作成（将来）、過去のレスポンスと比較（将来）、通信時間や失敗率を集計（将来）。
