# 要件定義

2026-10-24 に決めた要件定義（F21・F22 は 2026-10-29 追加）。設計は [05-design.md](05-design.md)。

## 目的と観測範囲

Web アプリ開発者が、local や本番環境で通信内容を確認したいときに、API 通信の詳細を確認できるようにするためのアプリ。

- 観測するのは、ブラウザから出る通信
- 宛先は localhost と本番環境の 2 つ。外部サービスへの通信は対象外
- 通信は「見るだけ」。書き換え・中継・止める機能は作らない
- 記録するのは、登録した観測対象のホスト（例：`localhost:3000`、本番のドメイン）だけ。それ以外の通信は中身を開かずに素通しする（F21、2026-10-29 追加）
- 本番は HTTPS が前提なので、暗号化された中身を見る仕組みが必須

## ユースケース

使う人はすべて「Web アプリ開発者」。

| No. | 側 | 目的 | 操作 |
| --- | --- | --- | --- |
| ① | クライアント | API の動きを確かめる | URL・メソッド・送る内容を入力して送信する |
| ② | クライアント | 結果を確かめる | 返ってきたステータスコード・ヘッダー・本文を見る |
| ③ | クライアント | 同じ確認を何度もする | 送ったリクエストを保存して再送する |
| ④ | 観測 | アプリが何を送っているか知る | ブラウザの通信を一覧で見る |
| ⑤ | 観測 | 目的の通信を探す | URL やステータスコードで一覧を絞り込む |
| ⑥ | 観測 | エラーの原因を探す | 失敗した通信の送った内容と返ってきた内容を見る |
| ⑦ | 観測 | 遅い原因を探す | 通信にかかった時間を見る |
| ⑧ | 観測 | あとで見直す | 過去の通信履歴を開く |

## 機能要件

F1〜F20 は 2026-10-24、F21・F22 は 2026-10-29 に追加。完了条件が空欄のものは「その機能が画面で使えること」を完了とする。

| ID | UC | 機能 | 完了条件 |
| --- | --- | --- | --- |
| F1 | ① | URL を入力して送信できる | localhost の API に GET を送り、結果が表示される |
| F2 | ① | メソッドを GET / POST / PUT / PATCH / DELETE から選べる |  |
| F3 | ① | ヘッダーを名前と値の形で追加・削除できる | 自分で決めたヘッダーを付けて送り、サーバー側で受け取れたと確認できる |
| F4 | ① | 本文（JSON）を入力して送れる | POST で送った JSON がサーバーに届く |
| F5 | ② | ステータスコードを表示し、成功・失敗が色でわかる |  |
| F6 | ② | レスポンスヘッダーを一覧で表示する |  |
| F7 | ② | 本文を表示し、JSON なら見やすく整形する |  |
| F8 | ② | かかった時間とサイズを表示する |  |
| F9 | ③ | 送ったリクエストに名前を付けて保存できる |  |
| F10 | ③ | 保存したリクエストを一覧から選んで再送できる | アプリを再起動しても保存したものが残っていて再送できる |
| F11 | ④ | 「観測開始 / 停止」ボタンがある |  |
| F12 | ④ | ブラウザの通信を、時刻・メソッド・URL・ステータスの一覧でリアルタイムに表示する | localhost のアプリを操作すると、その通信が一覧に増えていく |
| F13 | ④ | 本番（HTTPS）の通信も中身まで見られる | 本番アプリの通信の本文が読める |
| F14 | ⑤ | URL に含まれる文字で絞り込める |  |
| F15 | ⑤ | ステータス（成功 / 失敗）で絞り込める |  |
| F16 | ⑥ | 一覧の 1 行をクリックすると、送った内容と返ってきた内容を並べて見られる |  |
| F17 | ⑥ | 観測した通信を①の送信画面にコピーして送り直せる | 失敗した通信を少し直して再送できる |
| F18 | ⑦ | 一覧と詳細画面に、かかった時間（ミリ秒）を表示する |  |
| F19 | ⑧ | 観測した通信を PC に保存し、次回起動時も見られる |  |
| F20 | ⑧ | 履歴をまとめて削除できる |  |
| F21 | ④ | 観測対象のホストを、表示名を付けて登録・削除できる。登録したホストの通信だけを記録する | `localhost:3000` だけを登録して観測すると、一覧にはその通信だけが出て、ほかのサイトはブラウザで普通に表示できる |
| F22 | ⑤ | 一覧を「すべて」または登録したホスト 1 つ（例：ローカル / 本番）に切り替えて表示できる |  |

## 非機能要件

| ID | 分類 | 内容 |
| --- | --- | --- |
| N1 | 対応 OS | まず macOS で作って動かす。Windows は全機能の完成後に動作確認する段階として追加する |
| N2 | 履歴の量 | 観測した通信は最新 1,000 件まで残し、古いものは自動で消す |
| N3 | 大きなレスポンス | 本文が 10MB を超えたら先頭だけを表示し、サイズを知らせる |
| N4 | 速さ | 通信が起きてから 1 秒以内に一覧に出る |
| N5 | 安全 | 観測した内容は PC の中だけに保存し、外には送らない |
| N6 | 安全 | プロキシは自分の PC からしか使えないようにする |
